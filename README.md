# To-Do List App

A simple, clean **To-Do List web application** built with **TypeScript** and **Snowpack**. The app provides an easy way to add tasks, mark them as completed, remove individual tasks, and clear the entire list.

## Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🧹 Clear the entire task list
- 🌙 Dark-themed user interface
- 📱 Simple, responsive layout
- ⚡ Fast development server powered by Snowpack
- 🎉 Uses `canvas-confetti` for visual feedback

## Preview

The application provides a simple interface with:

- An input field for adding a new task
- A `+` button to add the task
- A list displaying all tasks
- Checkboxes for completing tasks
- `X` buttons for deleting individual tasks
- A `Clear` button for removing the list

## Technologies

- **TypeScript**
- **Snowpack**
- **HTML5**
- **CSS3**
- **canvas-confetti**
